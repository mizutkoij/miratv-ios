# ci50: 5.1ch サラウンド（2026-10-19）

- 5.1ch の番組（WOWOW・BS の映画、一部のスポーツ・音楽番組など）を、ステレオにまとめずに 5.1ch（L R C LFE Ls Rs）で出す
  - AirPods（Pro・Max・3 以降など）の空間オーディオで立体的に鳴る。頭の向きに合わせるかは iOS のコントロールセンターの設定どおり
  - 5.1ch に対応した AirPlay の機器（Apple TV・サウンドバーなど）には 5.1ch のまま届く
  - iPhone のスピーカー・普通のイヤホンでは iOS がステレオにまとめる（聞こえ方は今までどおり）
- ステレオの番組は今までどおり（空間オーディオで勝手に立体化しない）。主音声・副音声の切り替えもそのまま
- 設定 ›「5.1ch の番組を 5.1ch で出す」でオフにすると、これまでどおり端末でステレオにまとめる
- 画面の「原画質 · 5.1ch」の表示で確認できる（オフのときは「5.1ch→2ch」）
- 「録画」（動画で保存）は、録り始めたときの番組の音声に合わせて 5.1ch の AAC で保存する。途中で番組が替わって 2ch になった分の音は入らない
- サーバー側の変更はなし

## レビューで直したもの
- 5.1ch の番組を「録画」したとき、AAC の 5.1ch の並びの指定によっては落ちる可能性があった → AAC 用の並びにし、作れない端末ではステレオにまとめて保存
- 5.0ch など 6ch 以外の多チャンネルの番組でも、5.1ch で出しているかどうかを表示に出す
