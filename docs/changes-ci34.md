# ci34: サーバーに変換の負荷をかけない（2026-10-19）

- 設定「サーバーで変換する再生モードを使う」を追加。**既定はオフ**
  - オフのとき、再生モードは「原画質」「音声のみ」だけ。どちらも Mirakurun の TS をそのまま受けて端末でデコードする
  - EPGStation の `/api/config` も読みに行かず、モバイル回線での省データ自動切替もしない
  - オンにすると、これまでどおり HLS・変換（TS）が出る（見ている間 EPGStation が ffmpeg でエンコードし続ける）
- 設定「録画の CM を検出する」を追加（既定オン）。chapterd は音声だけを読んで無音を探す（エンコードなし、1 時間の番組で約 1 分・1 回だけ）。オフにすると CM の検出・スキップをしない
- 録画の再生は変更なし: TS は homeserver の /raw から直接、変換済み mp4 は保存済みのファイルをそのまま配信（再生時の変換はもともと無い）
