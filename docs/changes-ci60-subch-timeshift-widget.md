# ci59: サブチャンネルの録画・実装漏れ（2026-10-19）

## サブチャンネルの録画
- 録画の中に複数の番組が入っているとき、録画した局（サービス ID）の番組の映像・音声を選ぶ（これまでは FFmpeg がいちばん画質の良い映像を選ぶので、メインの HD が映ることがあった）
- 録画の途中でマルチ編成が始まる・終わると、映像・音声の PID が切り替わる。今の映像（音声）が届かなくなり、同じ番組の別の映像（音声）だけが 1.5 秒以上届いたら、そちらに付け替えて続ける（これまでは映像が止まる・音だけになっていた）
  - 副音声のように並んで届く別のストリームでは切り替えない
  - ログに「映像を付け替え: ストリーム 0 → 3」のように出る

## 実装漏れ
- 横画面の上のバー: ボタンが 7 個になって狭い機種であふれていた → ボタンの部分だけ横にスクロール
- 追っかけ再生中の実況: ライブのまま流れていた → ライブで届いたコメントを直近 40 分ぶん端末に貯めておき、見ている時刻（いま − 遅れ）に合わせて出す。ライブに戻ると元どおり
- 回線が細いとき: ライブを原画質で見ていて、データ切れが 1 分に 3 回あったら、自動で音声のみ（streamd があれば約 0.3Mbps）に切り替える。設定 ›「途切れが続いたら音声のみにする」でオフにできる

## 追っかけで追いつく
- 追っかけ再生中、シークバーの左に「追う」ボタン。押すたびに ×1.5 → ×2 → 等速
- 音程は変えずに速く流し、ライブの 3 秒手前まで来たら自動でライブに戻る（「ライブに追いつきました」）
- 実況コメントも見ている時刻に合わせて流れる

## 番組を探す → 予約・毎週録画
- 番組表の右上の 🔍: 言葉で番組を探す（EPGStation の番組検索。番組名、オンにすれば概要・詳細も）
  - 放送波で絞れる（すべて・地上波・BS・CS）。結果は日付ごと、放送中は緑、予約済みは「予約」
  - タップで番組詳細 → そのまま予約、または「毎週録画ルール」（ルールのキーワードは検索した番組名から）
  - 最近探したことば 10 件を覚える

## 診断
- 設定 ›「診断（ビルド・接続・最近のエラー）」
  - この端末: ビルド番号・iOS・メモリ・前回落ちたか・ログを送っているか
  - サーバー: Mirakurun・EPGStation・chapterd・streamd・web-bml・radio-web に同時に問い合わせ、つながるか・何 ms か
  - 直近のログ（新しい順、「エラーだけ」で絞れる）。ログの送信をオフにしていても端末の中には残す
  - 「まとめてコピー」で全部を 1 つの文章にしてコピー → そのまま不具合の報告に貼れる

## ホーム画面・ロック画面のウィジェット
- 「MiraTV」ウィジェット（小・中・大、ロック画面の長方形）
  - 次の録画（録画中ならそれも）と、いま放送中の地上波（中は 5 局、大は 12 局）
  - 番組が替わる時刻に合わせて更新（遅くとも 30 分ごと）。アプリで予約を足す・消すとすぐ更新
- ウィジェットはアプリの設定を読めないので、EPGStation はアプリの既定の URL（http://192.0.2.10:8888）を使う。Tailscale がつながっていないと「つながりません」
- 前の ci48 で入れたウィジェット拡張に入っているので、署名・インストールの手間は増えない

## レビューで直したもの
- サブチャンネル: マルチ編成が終わって元の PID に戻ったとき、元のストリームを読み飛ばしたままにして映像が止まり続けることがあった → 一度でも番組に入ったストリームは読み続ける。番組の中身が変わったら（シークで戻ったときも）読むストリームを決め直す。さらに FFmpeg の merge_pmt_versions で、PID が替わっても同じストリームとして続けられるように
- 付け替えた直後はキーフレームまで待つ（乱れた絵を出さない）。番組に映像が見つからなければ番組の区別なしで選び直す
- 追っかけの実況: 40 分を超えて古い分を消すとき、まだ出していないコメントを飛ばしていた
- 自動で音声のみ: streamd もワンセグも無いときは切り替えない（通信量が減らないため）。選局したら数え直す
- 横画面の上のバー: 入りきるならボタンをそのまま右寄せ、入らないときだけスクロール。番組名は残りの幅で省略
- 追いつく: streamd に届かなくなったとき、勝手に「追いつきました」とライブに戻らないように
- ウィジェット: 重複・競合で録画されない予約を「次の録画」に出さない。予約を読めなかったときは「予定なし」ではなくそう出す
- 番組を探す: 放送波を切り替えたとき、前の検索結果で上書きされないように。診断の同時実行を防ぐ
