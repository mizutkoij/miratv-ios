# ci44: 実況コメント・キャプチャ・続きから再生・ロック画面（2026-10-19）

## ニコニコ実況のコメント（「実況」ボタン、既定オフ。オン / オフは覚える）
- 録画: ニコニコ実況 過去ログ API（https://jikkyo.tsukumijima.net、非公式・個人運営）から、放送時刻の前後 1 分を含めて取得
  - 再生位置 → 放送時刻（録画の開始時刻 + 位置）に合わせて流す。シーク・CM スキップにも追従
  - 過去ログは 5 分ごとに集められるので、放送直後の録画は最後の数分ぶんがまだ無いことがある
- ライブ: NX-Jikkyo（ニコニコ実況互換のコメントサーバー。ニコニコ実況のコメントも取り込んでいる）の WebSocket
  - 要確認: コメント受信セッションに送る thread コマンドの形（ニコ生の旧来の形式に合わせた）
- 局 → 実況 ID: BS はサービス ID（jk101, jk141 …）、地上波は局名から系列で判定（jk1 NHK総合 … jk9 TOKYO MX、jk10〜14 独立局）
- 表示: 11 段、右から左へ約 5 秒、ue / shita（上下に固定 3 秒）、big / small、色コマンド。画面に 70 件まで
- 投稿はしない（読むだけ）

## キャプチャ（「写真」ボタン）
- いま映っている 1 枚を、表示の縦横比（DAR）に直して写真に保存（「追加のみ」の許可）。字幕・コメントは入らない
- 変換配信（HLS）と音声のみでは使えない。変換済み mp4 の録画は未対応

## 録画の続きから再生
- 5 秒ごとと閉じたときに位置を保存。15 秒未満・残り 90 秒未満は覚えない（見終わった扱いで消す）
- 開くと「続きから再生（mm:ss）」と出て、その位置から。「最初から」で先頭へ
- 録画一覧のサムネイルの下に、どこまで見たかのバー

## ロック画面・コントロールセンター（テレビ）
- 番組名・局名・局ロゴを表示
- ライブ: 再生 / 停止（ライブは一時停止できないので、停止 → 再生で選局し直す）
- 録画（TS）: 再生 / 一時停止・+30 / -15 秒・位置と長さ
- 変換済み mp4 は標準のプレイヤーが出す
- Dynamic Island（ライブアクティビティ）は別のターゲット（Widget Extension）が要るので次の段階
