# ci36: ワンセグと、流れているものの実測（2026-10-19）

## ワンセグ（再生モード「ワンセグ」、地上波のみ）
- 地上波の電波には、最初から低解像度のワンセグ放送（H.264 320×180 前後 + HE-AAC、約 0.3〜0.5Mbps）が入っている
- Mirakurun はそれを同じチューナーから別サービスとして取り出せるので、**サーバーは何も変換しない**
- 局のワンセグ = 同じ networkId で service_type 0xC0 のサービス（一覧には出していない）
- BS など、ワンセグの無い局に切り替えたら原画質に戻る

## 音声のみの取り方（上から順に使えるものを使う）
1. streamd（本放送の音声、映像を中継で除去、約 0.2〜0.3Mbps）
2. ワンセグの音声（地上波、約 0.3Mbps、音質はワンセグ相当）
3. 原画質を受けて端末で映像を捨てる（通信量は原画質と同じ）

## streamd の /probe
- `GET /probe/<serviceId>?seconds=10` で、その局の映像・音声・字幕・データ放送・SI が何 Mbps かを返す
- `/live` を閉じたときのログにも内訳を出す
