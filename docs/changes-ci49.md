# ci49: 番組表の昨日・7 日後、動画で保存（2026-10-19）

## 番組表
- 日付のチップを「昨日・今日・明日 … 7 日後」に（これまでは今日から 6 日後まで）
- その日の番組情報が無いときは、理由を出す
  - 昨日: EPGStation は終わった番組を消していくので、残っている分だけ出る（全部消えていれば「残っていません」）。録画した番組は録画タブ
  - 先の日: 放送の番組情報はおよそ 8 日先まで、近づくと増える

## 動画で保存（「写真」の横の「録画」）
- ライブ・録画の再生画面に「録画」ボタン。押すとその時点から書き始め、ボタンが「保存」になる。もう一度押すと写真アプリに動画で保存
- 最大 5 分（超えたら自動で保存）。H.264 + AAC の mp4（1080p、約 8Mbps。5 分で約 300MB）
- 端末でデコード済みの映像を iPhone のハードウェアエンコーダーで書くので、サーバーの負荷は無し
- 字幕・実況コメントは入らない（「写真」と同じ）
- 選局・録画でのシーク・画面を閉じると、書いている途中の分は捨てる
- ボタンが増えたので、操作のボタンは 4 列 × 2 段に

## レビューで直したもの
- 「保存」を素早く 2 回押したときに空の通知が出た・状態の更新が裏のスレッドからだった → 止める処理をメインで先に済ませてから書き出す
- 5 分を超えたあと、保存の合図が何度も出ていた → 1 回だけ
- アプリを背面に回した・PiP にしたときは、それまでの分で保存する（背面ではエンコーダーが使えないため）
- 地デジ（1440x1080）の画素比が書き出した動画に残り、縦長に見えることがある → 正方画素に
- 番組表: 読み込み前に一瞬「番組情報なし」が出た。昨日の番組表で、端末に残っていた分をサーバーの消えかけの分で上書きしていた → 端末の分を優先
