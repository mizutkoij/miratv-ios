# ci40: 再生しながら番組表など（ミニプレイヤー）（2026-10-19）

- 再生画面（ライブ・録画）を、タブの上に重ねる形に変更（以前は fullScreenCover）
  - アプリ全体で 1 つの `PlaybackSession` が「いま再生しているもの」を持つ
  - 再生画面は ×で閉じるまで作り直さないので、たたんでもエンジンは止まらない
- 左上の ⌄ で「たたむ」→ タブバーのすぐ上のミニプレイヤー（小さな映像・題名・消音 or 一時停止・×）
  - タップか上へはじくと全画面に戻る。× で再生を終了
  - たたんでいる間はタブを自由に切り替えられる（番組表・録画一覧・設定）
  - 各タブの一番下は、ミニプレイヤーの分だけ空ける
- 一覧でほかの局・録画を選ぶと、そちらに切り替わる（同じものなら広げるだけ）
- 横向きの全画面からたたむと縦に戻す
- ラジオを鳴らし始めたら、テレビの再生は閉じる
