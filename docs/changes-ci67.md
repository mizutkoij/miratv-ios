# ci67: 録画中の再生をより確実に・Release ビルド（2026-10-26）

## 録画中の録画
- これまでは、録画一覧を読んだ時点で「録画中」だった番組だけを追いかけ再生にしていた。一覧が古い（読んだあとに録画が始まった、字幕で探すから開いた等）と、普通の再生になって開いた時点の長さで止まっていた
  → 番組の終わりの時刻がまだ来ていなければ、chapterd に「まだ書き足されているか」を聞いて決める
- 普通の再生で端まで来たときも、ファイルがまだ伸びていれば、その位置から追いかけ再生に切り替えて続ける
- どちらにしたかをログに出す（設定 › 診断 で見られる）。「chapterd の /follow に届かない（follow.py が無い？）」と出たら、homeserver に server/follow.py が入っていない

## ビルド
- GitHub Actions のビルドを Release に（`-configuration Release`、コピー元 `Release-iphoneos`）。Swift のコードが最適化されるので、映像の受け渡しなど毎フレーム動く処理が軽くなる
- ipa の中から MiraTV.debug.dylib・__preview.dylib が無くなる（Debug 用のもの）
