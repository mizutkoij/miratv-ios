# ci48: ロック画面・Dynamic Island（2026-10-19）

再生中の局・番組と進み具合を、ロック画面と Dynamic Island に出すようにした（ライブアクティビティ）。

## 出るもの
- ライブ: 局・番組名・「LIVE」・番組の進み具合のバー（番組の開始〜終了）
- 追っかけ再生: 「-1:23」（ライブより何秒遅れているか）
- 録画: 番組名・残り時間・進み具合（一時停止中は止まった位置）
- Dynamic Island: 小さいときは左にアイコン（再生中 / 一時停止）、右に局名。長押しで広げると番組名とバー
- 再生画面を × で閉じると消える。設定 ›「ロック画面・Dynamic Island に表示」でオフにできる
- これまでのロック画面の「再生中」（コントロールセンターの再生・一時停止）はそのまま。ライブアクティビティはその上に出る

## 入れ方（Sideloadly）
- アプリの中にウィジェット拡張（MiraTVWidgets.appex、PlugIns フォルダ）が入るようになった
- Sideloadly の詳細設定で「Remove app extensions」（アプリ拡張を外す）がオンだと出ない → オフにする
- 無料の Apple ID では、拡張の分の App ID がもう 1 つ要る（1 週間に作れる App ID は 10 個まで）。足りないと署名で止まるので、そのときは拡張を外して入れれば今までどおり動く
- 入れたあと、iPhone の 設定 › MiraTV › ライブアクティビティ がオンになっているか確認

## 中身
- `Shared/NowPlayingAttributes.swift`: アプリと拡張で共通の中身（局・番組・一時停止・バーの始まりと終わり）
- `MiraTVWidgets/`: 表示（ロック画面・Dynamic Island）。ネットワークは使わない（局ロゴは出さない）
- `MiraTV/App/LiveActivity.swift`: 出す・更新・消す。中身が変わらなければ送らない（送りすぎると間引かれる）。前回落ちて残ったものも閉じるときに消す
- `TVNowPlaying.update` から一緒に更新するので、ライブ・追っかけ・録画の今の仕組みのまま動く
- project.yml: ターゲット MiraTVWidgets（app-extension）、アプリに `NSSupportsLiveActivities`

## レビューで直したもの
- 再生画面を切り替えたとき（ミニプレイヤーから別の局・録画を開いた等）、古い画面を閉じる処理で新しい画面の表示が消えることがあった → 表示には持ち主を付け、持ち主だけが消せるように
- ロック画面でスワイプして消した表示が、数十秒でまた出てきた → 消したら、その再生画面の間は出さない
- 設定のオン・オフがすぐ効くように
- 追っかけ再生のバーを、見ている位置（遅れた分）に合わせた。録画の残り時間を再生速度に合わせた
