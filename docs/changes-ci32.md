## 番組表（GuideView）
- 列の見出しが列より 4pt ずつ広く（`.frame` の外側に `.padding`）、右へ行くほど番組の列とずれていた → 幅の内側に余白を入れる
- その放送日（05:00〜翌 05:00）にかからない番組も描いていて、上端に潰れた箱が重なったり列の下にはみ出したりしていた → 範囲内だけ・ID の重複を除いて描く。列は `clipped()`

## 再生モード（QualitySheet / PlayerView）
- 選択肢が「原画質」＋ EPGStation の HLS だけだった。HLS の設定が無いと原画質しか出ず、選べない状態だった
- 追加:
  - **音声のみ**（id -2）: Mirakurun の原画質ストリームのまま、映像のパケットを読み捨ててデコードしない。CPU・電池をほとんど使わない（通信量は原画質と同じ）。映像の代わりに局ロゴと番組名
  - **変換（TS）**（id 1000+）: EPGStation の `stream.live.ts.m2ts` のうち無変換でないもの。`/api/streams/live/{id}/m2ts?mode=n` を端末のエンジンで再生するので、字幕・主/副・PiP が使える（データ放送は消える）
- `/api/config` の streamConfig は `live` 直下（api.yml の定義）と `live.ts` の下の両方を読む。HLS が出なかった原因の可能性あり
- 変換の選択肢が無いときは、シートに「config.yml の stream.live を確認」と出す

## 音声（主/副）
- ボタンが「番組表で二か国語と分かっている番組」でしか押せなかった。番組情報が取れていないと常に押せなかった
- 2ch の音声なら常に 主+副 → 主 → 副 と切り替えられる。5.1ch のときは「5.1ch」と表示して押せない
