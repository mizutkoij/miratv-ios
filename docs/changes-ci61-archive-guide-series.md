# ci60: アーカイブを番組表とシリーズで探す（2026-10-19）

録画タブ ›「アーカイブ」の上に「新着 / 番組表 / シリーズ」の切り替えを付けた。サーバー側は変更なし（端末の中の一覧から作る）。

## 番組表
- 日付を選ぶと、その日の放送を局 × 時刻に並べる。1 日は 5:00〜翌 5:00（テレビの区切り）
- ‹ › で 1 日ずつ、日付をタップで好きな日、「最新」で一番新しい日へ。開くとその日の最初の番組の少し前までスクロールする
- 局の並びはアーカイブの件数の多い順。局メニューで 1 局だけにできる
- 名前に終わりの時刻が無いので、箱の高さは「同じ局の次の番組の開始まで」と「大きさから見積もった長さ（約 16Mbps）」の短いほう
- 途中まで見た回は枠と点が accent、見た回はチェック

## シリーズ
- 番組名から話数・サブタイトル・日付・年を落として、同じ番組の回をまとめる（2 回以上あるものだけ）。最新の回が新しい順
  - 例: `ガオトラ！タイガース中継2026 阪神vs…(5．27)` → `ガオトラ!タイガース中継`、`ドラマ名 #12「…」` → `ドラマ名`、`アニメ名 第3話` → `アニメ名`
  - 「番組名 サブタイトル」の形は最初の区切りより前を使う（前が 4 文字未満なら使わない）
  - 規則は `MiraTV/Usenet/SeriesKey.swift`。外れても「まとまらない」だけで、再生や検索には影響しない
- 押すと回の一覧。「続きから見る / 次の回を見る / 最初の回から見る」のボタン（途中の回 → 最後に見た回の次 → 最初の回）
- 古い順 / 新しい順の切り替え。長押しで「見たことにする / 見ていないことにする」
- 検索欄と局メニューはシリーズにも効く（シリーズ名と局で探す）

## 次の回へ自動で
- 最後まで見たら（mp4 も TS も）8 秒の案内を出して、同じシリーズの次の回へ進む。「今すぐ再生」「やめる」。たたんでいればたたんだまま
- 再生画面の情報欄に「次の回」と「見終わったら次の回へ進む」のスイッチ
- 残り 90 秒を切ったら「見た」にする（続きの位置が消えるのと同じ基準）。「見た」は `nzbWatched.v1`（最大 5,000 件）

## レビューで直したもの
- 次の回の案内の間に戻して見始めた・スイッチを切ったときは、次へ進まない
- 日付の選択で、一番新しい日の次の（空の）日を選べてしまった
- シリーズの「最初の回から見る / 次の回を見る」が、ほかのシリーズの「見た」を見て決まっていた
- シリーズ名の末尾の「新」「再」「終」は前に空白があるときだけ消す（「明治維新」が「明治維」になっていた）
- mp4 の終わりの通知をメインスレッドで受ける。再生を閉じた後の「続き」の印を、位置の保存を待ってから読む

## 実機で見るところ
- シリーズのまとまり方（まとまりすぎ・まとまらなさすぎの例があれば規則を足す）
- 番組表の箱の高さ（mp4 の回はビットレートが低いので短めに出る）
- 一覧を作り直す時間（シリーズの計算で増えた分。7〜8 万件で数百 ms の見込み）
