# ci47: 字幕で探す（2026-10-19）

録画の字幕を文字として取り出しておき、ことばで場面を探せるようにした。取り出しは homeserver の chapterd が行う（ffmpeg も ARIB のデコーダーも要らない）。

## 使い方
- 録画の再生画面（TS）: CM スキップの行の右「字幕で探す」（横画面は上のバーの「文字」）
  - その録画の字幕が時刻つきで全部並ぶ。上の欄で絞り込み、行をタップするとその 1 秒前へ飛ぶ
  - 初めて開いた録画は取り出しを待つ（録画ファイルを 1 回読むだけ。進み具合が出る）
- 録画タブの右上の 🔍（字幕で探す）: 取り出し済みの録画すべてから探す
  - スペースで区切ると全部を含む行だけ。ひらがな・カタカナ、全角・半角、大文字・小文字は区別しない
  - 結果をタップすると、その録画をその場面（2 秒前）から再生
  - 「一覧にある録画 N 本の字幕を取り出す」で、まとめて取り出せる（1 本ずつ順番。録画一覧で読み込んである分だけ）

## サーバー（homeserver）
- `server/chapterd.py` と一緒に `server/arib_caption.py`・`server/arib_tables.json` を同じフォルダ（~/miratv-chapterd/）に置いて再起動
- 取り出した字幕は `~/.cache/miratv-chapters/captions/<videoFileId>.json`（1 時間の番組で数十 KB）
- 負荷: 字幕のパケットだけを正規表現で拾うので CPU はほぼ使わない（450MB を 0.5 秒）。ほぼディスクを 1 回読む時間だけ。サービスの設定どおり IO は idle 優先度なので録画の邪魔はしない
- CM 検出と同じ 1 本の作業列に並ぶ（同時には 1 本だけ）

## 中身
- `arib_caption.py`: TS の PAT/PMT から字幕の PID（component_tag 0x30）を見つけ、字幕 PES の第 1 言語の字幕文を ARIB STD-B24 の 8 単位符号から文字にする。漢字・ひらがな・カタカナ・英数・JIS 半角カナ・追加記号（♬ や 🈑 など、aribb24.js の表）・既定マクロに対応。DRCS（局ごとの外字）は読み飛ばす
  - 時刻は最初の映像・音声の PTS からの秒（アプリのシークと同じ）。33 ビットの PTS の折り返しも扱う
  - 単体でも試せる: `python3 arib_caption.py 録画.ts`
- chapterd: `GET /captions/<videoFileId>?name=&rid=`（取り出し・結果）、`GET /captions/search?q=`（全録画から検索）
- アプリ: `CaptionSearchView.swift`（1 本の一覧・全体検索）。検索から開くときは PlaybackSession の seekRequest でその位置へ

## まだ確かめていないこと
- 録画中の番組では「字幕で探す」を出さない（録画が終わってから）
- 実際の放送の字幕でのテスト（ここでは合成した字幕で確認）。おかしな文字が出たら、その録画で `python3 arib_caption.py 録画.ts | head -50` の結果を送ってください

## レビューで直したもの
- chapterd: 同じ録画への要求が同時に来ると作業の列が止まり、CM 検出も動かなくなった → 二重に並べない・1 件の失敗で止まらない
- chapterd: 録画中のファイルを毎回読み直していた。検索の索引をメモリに抱えず、毎回ファイルから読む（メモリ上限 256MB を超えないように）。新しい録画から順に上限を切る
- 字幕の文字: proportional の英数・ひらがな・カタカナの対応が 1 つずれていた。文字の繰り返し（RPC）、JIS 互換漢字、壊れたパケットの読み飛ばし、PTS の折り返しをまたぐ開始位置を修正
- アプリ: まとめて取り出しを「やめる」と「接続できません」と出ていたのを修正
