# MiraTV デザイン仕様（SwiftUI 実装用）

キャンバスのモックアップ 10 画面を実装に落とすための仕様です。
値は `mockups/*.dc.html` から抜き出したもので、迷ったらそちらが正です。
色とフォントは `Theme.swift`（そのまま使える）と `tokens.json` にも同じ値があります。

- 画面サイズの基準: iPhone 390×844（縦）/ 844×390（横）
- 上端 54〜58px はセーフエリア、下端 30px はホームインジケーター分。SwiftUI ではセーフエリアに任せて、モックの数値は足さない
- ダークモード固定（`.preferredColorScheme(.dark)`）

## 2. 共通部品

- **TabBar**（5 タブ）: テレビ / 番組表 / ラジオ / 録画 / 設定。選択中は `accent` で太字、他は `text4`。上に `divider` の線
- **SegmentedPills**: 地上波 / BS / CS、予約 / 録画済み / ルール。地 `surface`、選択ピルは `accent` 地に `onAccent` 文字
- **Chip**: 選択は `accent` 地、非選択は `surface` 地＋`border` 枠＋`text2` 文字
- **LogoTile(size)**: `logoTile` 地。実ロゴ（Mirakurun `/api/services/{id}/logo`、EPGStation は `hasLogoData`）を `scaledToFit` で載せる。ロゴがなければ枠を出さず「番号＋局名」だけ
- **ProgressBar(progress)**: 3pt、地 `border`、値 `accent`
- **StatusLine**: 7pt の丸（接続中は `live`）＋ `text3` 13pt
- **MiniPlayer**: `raised` 地、角丸 16、枠 `#2A3038`、左右 8 の外余白。左にアートワーク 40×40、右に 44pt の丸い再生ボタン（`accent`）。アーカイブ再生中は上に進行バー、-15 / +30 ボタン
- **BottomSheet**: `scrim` の上に `surface` のシート（`.sheet` + `presentationDetents` で可）

## 3. 画面ごと

### チャンネル一覧（Main）
1. ヘッダー: タイトル「チャンネル」＋ StatusLine「自宅 Mirakurun · チューナー 2/4 空き」、右に 44pt の丸ボタン（サーバー設定）
2. SegmentedPills: 地上波 / BS / CS
3. 行カード（タップで再生）
   - 左 64pt 幅: LogoTile 64×36、下に「5ch」（Mono 12 / 600、`text2`）
   - 右: 1 行目 局名（13、`text3`）と時刻「18:00–20:54」（Mono 11、右寄せ）／ 2 行目 番組名（15 / 700、1 行で省略）／ 3 行目 ProgressBar ／ 4 行目「次 20:54 [番組名]」（12、`text4`）
   - 再生中の局は `rowActive` 地＋`#3A3220` 枠
4. TabBar

### 再生（縦）（Player）
1. 映像 390×219（16:9、DAR で補正）。左上に 36pt の閉じる（下向き矢印、黒 55%）。字幕は下 14pt に中央寄せ、`captionBg`、15 / 500、色付き字幕はその色のまま
2. 操作行: 5 等分のボタン（高さ 52、角丸 12、アイコン 20＋ラベル 11）: 字幕（ON の時は `accent` 地）/ 音声「主」/ データ「d」/ PiP / 全画面。下に `divider`
3. 番組情報（左右 20）: LogoTile 40×22 ＋「5 テレビ朝日」（番号は `accent`）＋「·」＋時刻、右端に再生モードのチップ「原画質 · 5.1ch ▾」（高さ 28、タップで再生モードシート）→ 番組名 21 / 700 → ProgressBar → 概要 13（3 行で折りたたみ）
4. 「ほかのチャンネル」: 148 幅のカードを横スクロール（上 83pt の箱に LogoTile 48×27 と右下に番号、下に局名と番組名）。左右スワイプで選局
5. 「このあと」: 時刻（Mono 13、幅 44）＋番組名 14

### 再生（横・全画面）（PlayerLandscape）
- 映像は高さいっぱいの 16:9、左右の余りは黒
- タップで操作パネルを出し入れ:
  - 上バー（`overlayBar`）: 縦表示に戻す（44 の丸）、LogoTile 64×36、局名 13 ＋番組名 17 / 700、右に 字幕（ON は `accent`）/ 主音声 / d / PiP（高さ 40 のカプセル）
  - 右端: 選局 ▲▼（44×56、角丸 14、上下に次の局の番号）
  - 下バー: 開始時刻 — ProgressBar(4) — 終了時刻 ＋ LIVE バッジ（`live` 地）
- **字幕はパネル表示中は下から 76、非表示時は 24**（パネルに隠れないよう逃がす）。20 / 500

### データ放送＋リモコン（DataBroadcast）
- 上: データ放送の領域 390×219（web-bml の 960×540 を縮小表示する WKWebView）
- 情報行: 「5 テレビ朝日 · データ放送」＋「最後の入力」、右に「データ終了」（高さ 36 のカプセル）
- リモコン（左右 24、縦の間隔 18）:
  - 色ボタン 4 つ（高さ 44、角丸 12、ARIB 色）
  - 左に「戻る」「d」（72×44、d は `accent` の枠と文字）、右に十字キー（直径 176 の円、上下左右 48pt、中央の決定 68pt の円は `accent`）
  - 数字キー 1〜12（6 列、高さ 44、角丸 10）
- 決めかね: 常時表示か、引き出し式か

### 番組表（Guide）
- ヘッダー: タイトル＋右に放送波の切替「地上波 ▾」、日付チップ（今日 / 翌日…）
- 列見出し: 左 40pt は時刻列、各局 116pt 幅（LogoTile 36×20 ＋番号 12 ＋局名 11）
- グリッド: **1 分 = 2pt**（1 時間 120pt）。番組ブロックは左右 3pt 内側、高さ −4、角丸 8、地 `row`。放送中は `#221E14` 地＋`#4A3B1A` 枠
- 予約バッジ: 右上に高さ 16 のカプセル「録」（`rec`）／「競合」（`warn`）
- 現在時刻の線: 2pt の `accent` ＋左端に時刻ラベル
- 番組をタップ → 番組詳細シート

### 再生モード（Quality）— ボトムシート
- タイトル「再生モード」＋右に回線状態（Wi-Fi / モバイル）
- ラジオ選択のカード 4 枚（角丸 14、選択中は `accent` の 1.5 枠＋`accentTint` 地）:
  | モード | 配信元 | スペック | できること |
  |---|---|---|---|
  | 原画質 | Mirakurun | MPEG-2 TS · 1440×1080i · 約15Mbps | 字幕◯ データ放送◯ 5.1ch◯ |
  | 高画質変換 | EPGStation | H.264 · 720p · 約3Mbps | 字幕◯（設定次第）データ放送× |
  | 省データ | EPGStation | H.264 · 360p · 約0.8Mbps | 同上 |
  | 音声のみ | EPGStation | AAC 2ch 128kbps | 画面オフ・バックグラウンド |
  - 実装では EPGStation `/api/config` の streamConfig から選択肢を作る
- 下にトグル 2 つ: 「モバイル回線では自動で省データ」「画面ロック中は音声のみに切替」

### 番組詳細・録画予約（ProgramDetail）— ボトムシート（上から 150）
- LogoTile 48×27 ＋「4 日テレ」、右に閉じる（36 の丸）
- 番組名 22 / 700、日時（Mono 13）、ジャンル・字・デのタグ（11、`borderStrong` 枠）
- 予約済みバナー（`recTint`）: 「録画予約済み」＋チューナー・保存形式
- 競合バナー（`warnTint`）: ⚠ ＋説明文
- 概要 13
- 下に固定: 主ボタン「録画予約」（高さ 52、`rec` 地）→ 予約後は「予約を取り消す」（透明地＋`#5A2A26` 枠＋`recText` 文字）、その下に 2 次ボタン 2 つ「毎週録画ルール」「録画オプション」

### 録画（Recordings）
- タイトル＋StatusLine「EPGStation 同期済み · 空き [容量]」、SegmentedPills: 予約 / 録画済み / ルール
- 予約: 行カード（左に日付 11＋開始時刻 Mono 15、中央に局・番組名・状態「予約 / ● 録画中 / ▲ 競合 / ルール予約」、右に 10pt のドット）。録画中は枠 `#5A2A26`、競合は枠 `#5C4718`
- 録画済み: サムネイル 136×76（右下に長さ）＋番組名 14 / 700＋局・日時＋ファイル種別
- ルール: キーワード 15 / 700 ＋条件 12、右に予約数

### ラジオ（Radio）
- タイトル＋StatusLine「radio-web · 219 局が再生可」、検索欄（高さ 40、`surface`、角丸 12）、地域チップ
- 行カード: LogoTile 64×32 ＋局名 15 / 700 ＋配信元タグ（10）／今の番組 12、右に「アーカイブ」（`accent`）/「ライブ」（`text3`）/「未対応」（`muted`）
- 下に MiniPlayer（ライブ中は「LIVE」を `recText`）

### ラジオ局詳細（RadioStation）
- 戻る（44）＋LogoTile 64×32 ＋局名 18 / 700 ＋「radiko · 関西」
- 「ライブで聴く」カード（`accentTint` 地、`#3A3220` 枠、左に 44 の再生ボタン、右に LIVE）
- 日付チップ（今日 / 昨日 / 14(水)…過去 7 日）
- 番組表: 時刻（Mono 13、幅 48）＋番組名 14 / 700 ＋出演者 12、右に「▶ / 再生中 / 次に再生」。アーカイブのない回は `muted` で押せない
- MiniPlayer（アーカイブ用）: 進行バー、番組名、「昨日 09:00 · 0:42:10 / 2:00:00」、-15 / 再生 / +30
- アーカイブ準備中（初回 40 秒前後）は状態行に「アーカイブを準備中… N秒」
